# Character Controller Setup Guide (Unity 6.3)

## Компоненты

### 1. PlayerInputManager
Управляет считыванием инпута через Input System с использованием `InputActionReference`.

**Требуемые поля:**
- `Move Action` - InputActionReference для движения (типа Value Type: Axis2D)
- `Look Action` - InputActionReference для поворота камеры (типа Value Type: Axis2D)
- `Sprint Action` - InputActionReference для спринта (типа Value Type: Digital/Button)
- `Jump Action` - InputActionReference для прыжка (типа Value Type: Digital/Button)
- `Crouch Action` - InputActionReference для приседания (типа Value Type: Digital/Button)

### 2. PlayerCharacterController
Основной контроллер персонажа с использованием CharacterController для физики.

**Требуемые компоненты:**
- CharacterController (на том же GameObject)
- PlayerInputManager (ссылка на компонент)

**Параметры:**
- `Move Speed` - базовая скорость движения
- `Sprint Speed` - скорость спринта
- `Crouch Speed` - скорость движения при приседании
- `Acceleration` - ускорение при разгоне
- `Deceleration` - замедление при торможении
- `Jump Force` - сила прыжка
- `Gravity` - значение гравитации
- `Ground Layer` - слой земли для проверки касания
- `Ground Check Distance` - дистанция проверки касания земли (0.1 оптимально)
- `Crouch Height` - высота персонажа при приседании (0.6 оптимально)
- `Crouch Height Speed` - скорость изменения высоты при приседании
- `Head Collision Distance` - расстояние проверки удара головой при прыжке (0.3 оптимально)
- `Obstacle Layer` - слой препятствий/потолков для проверки удара головой
- `Stand Check Distance` - расстояние проверки возможности встать из приседа (0.1 оптимально)

### 3. CameraController
Контроллер камеры с Cinemachine. Ограничивает вращение камеры по вертикали (pitch).

**Требуемые компоненты:**
- CinemachineVirtualCamera (дочерний объект камеры)
- PlayerInputManager (ссылка на компонент)
- PlayerCharacterController (ссылка на компонент, автоматически находится)

**Параметры:**
- `Camera Rig` - Transform объекта с камерой (если None, найдётся автоматически)
- `Virtual Camera` - ссылка на CinemachineVirtualCamera (если None, найдётся автоматически)
- `Character Controller` - ссылка на контроллер персонажа
- `Look Sensitivity` - чувствительность камеры
- `Min Pitch` - минимальный угол поворота вверх (например, -90)
- `Max Pitch` - максимальный угол поворота вниз (например, 90)
- `Normal Camera Height` - высота камеры при нормальной позиции (0.6 оптимально)
- `Crouch Camera Height` - высота камеры при приседании (0.2 оптимально)
- `Camera Height Speed` - скорость изменения высоты камеры (5.0)

## Инструкция по настройке в Unity

1. **Создайте Input Actions:**
   - Откройте Window > Input System
   - Создайте новый Input Action Asset
   - Добавьте Action Map "Player"
   - Добавьте Actions:
     - "Move" (Value Type: Axis 2D / WASD)
     - "Look" (Value Type: Axis 2D / Mouse Delta)
     - "Sprint" (Value Type: Digital / Shift, Gamepad Right Trigger)
     - "Jump" (Value Type: Digital / Space, Gamepad Button South)
     - "Crouch" (Value Type: Digital / Ctrl, Gamepad Button East)

2. **Настройте GameObject персонажа:**
   - Добавьте CharacterController компонент
   - Установите высоту (Height) и радиус (Radius)
   - Добавьте PlayerInputManager скрипт
   - Добавьте PlayerCharacterController скрипт
   - Задайте ссылки на Input Actions в инспекторе

3. **Настройте Cinemachine камеру:**
   - Создайте CinemachineVirtualCamera как дочерний объект персонажа
   - Настройте Follow и Look At на персонажа
   - Добавьте CameraController скрипт на объект с контроллером
   - Задайте ссылку на виртуальную камеру
   - Подстройте параметры камеры (Damping, Distance, Height и т.д.)

4. **Маски слоёв:**
   - Убедитесь, что создана маска слоя "Ground" для земли/платформ
   - Убедитесь, что создана маска слоя для потолков/препятствий (или используйте тот же слой)
   - Установите Ground Layer в PlayerCharacterController для проверки земли
   - Установите Obstacle Layer в PlayerCharacterController для проверки удара головой

## Управление (WASD + мышь)

- **W/A/S/D** - движение вперёд/влево/назад/вправо
- **Shift** - спринт (ускорение, отключает приседание)
- **Space** - прыжок (только когда на земле, отключает приседание)
- **Ctrl** - приседание (работает в любом состоянии, включая полёт)
- **Мышь** - поворот камеры (горизонтальный и вертикальный)
  - Вверх/Вниз - поворот камеры вверх/вниз (ограничен от -90 до 90 градусов)
  - Влево/Вправо - поворот персонажа

## Особенности приседания

- **Может приседать в любой момент** - даже в воздухе во время прыжка
- **Скорость движения** снижается до `crouchSpeed` (по умолчанию 2, что в 2.5 раза медленнее нормальной ходьбы)
- **Высота персонажа** плавно изменяется от полной высоты до `crouchHeight` (0.6 единиц)
- **Высота камеры** синхронизируется с приседанием
  - При нормальной позиции: `normalCameraHeight` (0.6)
  - При приседании: `crouchCameraHeight` (0.2)
  - Смещение применяется плавно со скоростью `cameraHeightSpeed`
- **Центр CharacterController** корректируется для правильной физики
- **Спринт невозможен** при приседании
- **Анимация** поддерживает параметр `IsCrouching` (bool) для синхронизации

### Проверка при встаивании из приседа

- **Работает только из приседа** - проверка происходит при попытке встать (`inputManager.IsCrouchPressed == false` и `_isCrouching == true`)
- **Используется Raycast** для обнаружения препятствий на расстоянии `standCheckDistance` (0.1 по умолчанию)
- **При обнаружении препятствия:**
  - Игрок остается в приседе
  - Продолжает получать ввод от игрока, чтобы при появлении места можно было встать
- **При достаточном свободном месте:**
  - Проверка возвращает `true`
  - Персонаж начинает встаивать (высота плавно меняется)

## Проверки коллизий головой

### Удар головой при прыжке

- **Работает только во время прыжка** - проверка происходит, когда скорость восхождения положительна (velocity.y > 0)
- **Использует Raycast** для обнаружения препятствий на расстоянии `headCollisionDistance` (0.3 по умолчанию)
- **При обнаружении препятствия:**
  - Останавливает восхождение персонажа
  - Устанавливает вертикальную скорость на небольшое отрицательное значение
  - Позволяет гравитации действовать нормально
- **Слой препятствий** должен быть настроен в `Obstacle Layer` (используются потолки, висячие объекты и т.д.)

### Проверка встаивания из приседа

- **Работает только из приседа** - проверка происходит при попытке встать
- **Используется Raycast** для обнаружения препятствий на расстоянии `standCheckDistance` (0.1 по умолчанию)
- **При обнаружении препятствия над головой:**
  - Игрок остается в приседе автоматически
  - Продолжает преобразовываться, когда появляется место
- **При свободном пространстве:**
  - Игрок может встать нормально

## Пометки и советы

- Используется Raycast для проверки касания земли, что более надёжно чем встроенная проверка CharacterController
- Animator поддерживает параметры: "Speed" (float) и "IsGrounded" (bool)
- Система использует плавное изменение скорости через Lerp для более естественного движения
- Pitch камеры ограничен, но yaw вращает сам персонаж (более игровой подход)
- Убедитесь, что у персонажа есть Animator если вы хотите использовать анимации

## Особенности прыжка и инерции

- При старте прыжка фиксируется горизонтальная скорость (инерция). Пока игрок находится в фазе прыжка, горизонтальная скорость не изменяется под вводом.
- Во время прыжка игрок **не может менять направление/скорость движения**, но может вращать камеру и переходить в состояния приседа/стоя (приседание/вставание в воздухе допускается, вставание проверяется на наличие места).
- При касании земли фаза инерции завершается, и управление движением возвращается в обычный режим.
- Это поведение помогает реализовать реалистичную физику прыжка и избегать мгновенного маневрирования в воздухе.
